# tg-ai - Telegram MCP-сервер для AI-агентов

> при расхождении верен он.

**tg-ai - это локальный [MCP](https://modelcontextprotocol.io)-сервер (Model
Context Protocol), который даёт любому AI-агенту «руки» и «глаза» в вашем
_личном_ Telegram-аккаунте.** Отправляйте сообщения от своего имени, читайте
ответы, ищите по всей истории переписки за миллисекунды и пишите ответы, которые
действительно звучат как вы - не выходя из терминала или IDE.

Работает с Claude Code, Claude Desktop, Cursor, Antigravity, Codex, Windsurf,
VS Code, Gemini CLI, Cline, Zed, Qoder, Kimi, Trae, Warp, JetBrains AI и любой
другой программой, которая поддерживает протокол MCP.

Всё работает на вашей машине. Архив ваших переписок никогда не покидает
`127.0.0.1`.

## Что такое tg-ai

tg-ai - это MCP-сервер для Telegram, который полностью работает на вашем
компьютере. MCP - открытый стандарт, позволяющий AI-агенту вызывать инструменты;
tg-ai публикует девять таких инструментов, так что агент может работать с вашим
Telegram-аккаунтом так же, как это делали бы вы.

Это **не бот**. Сервер управляет вашим настоящим пользовательским аккаунтом
через MTProto (библиотека [Telethon](https://docs.telethon.dev/)): сообщения
приходят от вас, попадают в те же чаты, которыми вы уже пользуетесь, и доходят до
людей, которые никогда не стали бы общаться с ботом.

Быстрым и безопасным его делают две вещи:

- **Локальный архив в PostgreSQL.** История один раз синхронизируется в Postgres
  с полнотекстовыми и триграммными индексами. Поиск идёт в базу, а не в API
  Telegram - поэтому он мгновенный, безлимитный и не несёт риска бана.
- **Send Guard, который нельзя отключить.** Писать незнакомым людям с личного
  аккаунта - самый быстрый способ получить бан, поэтому tg-ai просто отказывается
  это делать. Флага `force` нет, и это сделано намеренно.

| Вы говорите агенту | Что происходит |
| --- | --- |
| «Отправь саммари этой сессии @anna» | Агент составляет текст и отправляет его от вашего имени, разбив на части при необходимости |
| «Есть новые сообщения?» | Вы получаете список тех, кто ждёт ответа, и что они написали - без отметки «прочитано» |
| «Что ответила @anna?» | Живое чтение из Telegram: ответ минутной давности уже здесь |
| «Найди адрес, который мне присылали в прошлом году» | Мгновенный поиск по всему архиву, на любом языке, без единого запроса к API Telegram |
| «Ответь @anna про встречу» | Агент читает, как вы пишете именно ей, и составляет ответ в вашем стиле |

## Быстрый старт

Нужны Python 3.12+, [`uv`](https://docs.astral.sh/uv/),
[`just`](https://just.systems) и Docker.

```bash
git clone https://github.com/anrysys/tg-ai.git
cd tg-ai

just setup                       # venv + зависимости + .env
$EDITOR .env                     # укажите TG_API_ID и TG_API_HASH
just db-up                       # PostgreSQL на 127.0.0.1:5434
just tg-auth                     # интерактивный вход: телефон, код, 2FA
just tg-sync-targets @anna @bob  # сначала архивируем тех, кто важен (быстро)
just tg-sync-full                # потом всех остальных (часы; возобновляемо)
just mcp-add                     # регистрация в Claude Code
```

`TG_API_ID` и `TG_API_HASH` берутся на <https://my.telegram.org> → API
development tools.

`just tg-auth` **обязательно запускать в настоящем терминале** - он спрашивает
код из SMS, а MCP-сервер не умеет ничего спрашивать.

Затем перезапустите агента и попросите его вызвать `tg_whoami()`.

> ### ПРЕДУПРЕЖДЕНИЕ ПРОТИВ БАНА: задайте `TG_LANG_CODE` до входа
>
> **`TG_LANG_CODE` должен совпадать с языком интерфейса официального приложения
> Telegram на вашем телефоне.** Приложение на русском - ставьте `ru`. На
> украинском - `uk`. На испанском - `es`. По умолчанию стоит `en` только
> потому, что это публичный репозиторий и ни один язык не подходит всем; для
> вас это значение **небезопасно**, если у вас в приложении не английский.
>
> Каждое соединение сообщает Telegram `lang_code` и `system_lang_code` - рядом с
> номером телефона и `api_id`, который Telegram уже годами видит из
> официального приложения. Если в приложении `ru`, а этот клиент на каждом
> соединении говорит `en`, это противоречие в собственных данных Telegram, на
> аккаунте, который использование неофициального API и так поставило под
> наблюдение. Совпадение не стоит ничего. Несовпадение добавляет сигнал даром.
>
> Задайте это в `.env` вместе с `TG_TIMEZONE` и `TG_QUIET_HOURS` - и больше не
> трогайте: они повторно отправляются при каждом переподключении, поэтому
> изменение задним числом меняет запись в вашем же разделе
> **Настройки -> Устройства**.

### Сначала архивируйте тех, кто важен

На аккаунте с сотнями диалогов полная выгрузка занимает часы и упирается в лимиты
Telegram. `just tg-sync-targets` архивирует только названных вами людей, поэтому
поиск по этим перепискам заработает за минуты. Цель распознаётся по username (с
`@` или без), номеру телефона, числовому id, имени, фамилии или полному имени;
всё, что ни с чем не совпало, будет названо явно - опечатка сразу видна:

```bash
just tg-sync-targets @anna "Anna Petrova" +380501234567
```

Запуск `just tg-sync-full` после этого ничего не стоит для уже
заархивированных диалогов - вставка идемпотентна.

## Установка в вашем AI-клиенте

Все клиенты запускают один и тот же stdio-сервер; отличаются только файл
конфигурации и имя ключа. Везде, где написано `/absolute/path/to/tg-ai`,
подставьте вывод `pwd` из склонированного репозитория.

### Claude Code

```bash
just mcp-add
```

Или вручную:

```bash
claude mcp add tg-ai -s user -- /absolute/path/to/tg-ai/.venv/bin/python /absolute/path/to/tg-ai/server.py
```

### Claude Desktop, Cursor, Windsurf, Antigravity, Gemini CLI, Cline

Один и тот же блок, в конфиге вашего клиента:

```json
{
  "mcpServers": {
    "tg-ai": {
      "command": "/absolute/path/to/tg-ai/.venv/bin/python",
      "args": ["/absolute/path/to/tg-ai/server.py"],
      "cwd": "/absolute/path/to/tg-ai"
    }
  }
}
```

### VS Code (Copilot agent mode)

VS Code использует ключ `servers`, а не `mcpServers`. Файл `.vscode/mcp.json`:

```json
{
  "servers": {
    "tg-ai": {
      "type": "stdio",
      "command": "/absolute/path/to/tg-ai/.venv/bin/python",
      "args": ["/absolute/path/to/tg-ai/server.py"]
    }
  }
}
```

### Codex CLI

Codex использует TOML. Файл `~/.codex/config.toml`:

```toml
[mcp_servers.tg-ai]
command = "/absolute/path/to/tg-ai/.venv/bin/python"
args = ["/absolute/path/to/tg-ai/server.py"]
```

### Остальные клиенты

Qoder, Kimi, Trae, Warp, Zed, JetBrains AI Assistant, Continue, OpenCode и другие
читают JSON той же формы. Уточните в документации своего клиента путь к конфигу и
имя ключа - некоторые используют `servers` или `context_servers` вместо
`mcpServers`. Транспорт - stdio; HTTP-режима нет.

Полный список с точными путями - в
[английском README](../../../README.md#install-in-your-ai-client).

## Девять инструментов

| Инструмент | Назначение |
| --- | --- |
| `tg_send_message(target, message)` | Отправка от вашего имени. Блокирует отправку незнакомым, режет длинный текст, выдерживает паузы |
| `tg_get_recent_messages(target, limit=10)` | Последние сообщения с человеком, вживую |
| `tg_get_unread_dialogs(limit=5)` | Кто вам написал |
| `tg_search_local_history(query, target_username=None, limit=50)` | Полнотекстовый поиск по локальному архиву |
| `tg_add_contact(phone_or_username, first_name, last_name="")` | Добавить контакт - осознанный способ разблокировать отправку новому человеку |
| `tg_get_dialog_persona(target, samples=12)` | Как вы пишете конкретному человеку: сохранённая персона, измеренный стиль, реальные примеры |
| `tg_set_dialog_persona(target, addressing, tone, relationship, notes="", overwrite=False)` | Записать этот стиль. Никогда не перезаписывает молча |
| `tg_list_dialog_personas(limit=20)` | У каких диалогов есть персона, а у каких нет |
| `tg_whoami()` | Health check: аккаунт, сессия, база, архив |

Полные сигнатуры: [docs/30-api/mcp-tools.md](../../30-api/mcp-tools.md).

## Dialog Persona: ответы, которые звучат как вы, а не как нейросеть

Ответ, написанный в дефолтном регистре модели, мгновенно считывается любым, кто
вас знает. Вы не пишете начальнику так, как пишете жене, и ни с кем из них не
общаетесь так, как ChatGPT общается со всеми.

**Dialog Persona** - это профиль стиля для каждого чата отдельно. Одна персона на
диалог, хранится локально и подставляется модели **до** того, как она начнёт
писать.

### Что именно измеряется в стиле общения

Измеряется автоматически и **только по вашим собственным исходящим
сообщениям**, на любом языке, без участия LLM. Восемнадцать сигналов:

| Группа | Что учитывается |
| --- | --- |
| **Длина** | Медианная длина сообщения, 90-й перцентиль, ваше самое длинное сообщение, медианное число слов, медианное число предложений |
| **Ритм** | Доля коротких ответов (25 символов и меньше - ваши «ок», «да», «делаю»), доля многострочных сообщений и **burst rate**: как часто вы дописываете следующее сообщение в течение 90 секунд вместо одного длинного |
| **Пунктуация** | Как часто вы ставите точку в конце, как часто используете `?`, `!` и многоточие |
| **Типографика** | Как часто начинаете сообщение со строчной буквы, доля сообщений с эмодзи, как часто кидаете ссылки |
| **Язык** | Смесь алфавитов - латиница, кириллица и другие - с долей каждого, чтобы ответ пришёл на том языке и в той письменности, которую вы реально используете в этом чате |
| **Окно анализа** | Сколько сообщений измерено и за какой период |

### Что записывает ваш агент

Четыре коротких поля с ограничением длины - то, что нельзя измерить числами.
Их пишет ваш агент после чтения ваших настоящих сообщений, и это единственное
место, где живёт формальность обращения:

| Поле | Пример | Лимит |
| --- | --- | --- |
| `addressing` | Обращение на «ты» или на «вы», и как именно вы человека называете | 79 символов |
| `tone` | «тепло, коротко, сухой юмор» | 119 символов |
| `relationship` | «коллега, два года» | 119 символов |
| `notes` | Ещё одна привычка, которую стоит воспроизводить | 239 символов |

Формальность и различие «ты»/«вы» намеренно отданы агенту, а не зашиты в код:
в коде это потребовало бы словаря местоимений для каждого языка, а проект должен
работать в любом алфавите.

### Почему это не скатывается в имитацию нейросети

Четыре решения, каждое покрыто тестами:

- **Анализируются только ваши слова.** Каждый запрос фильтрует `is_outgoing`.
  Сообщения собеседника не доходят до анализатора, поэтому написанное им не может
  повлиять на то, как звучите вы (`SPEC-PSN-002`).
- **Персона не может учиться на черновиках самого AI.** Каждое отправленное этим
  сервером сообщение попадает в архив точно так же, как написанное вами вручную.
  Поэтому окно анализа **заморожено** на момент создания: `baseline_message_id`
  вообще отсутствует в UPDATE-запросе. Без этого персона после нескольких
  сгенерированных ответов начала бы моделировать саму модель - и, поскольку вывод
  модели стабильнее человеческого письма, результат читался бы _лучше_, а значит
  дрейф был бы незаметен (`SPEC-PSN-003`,
  [ADR-0008](../../20-architecture/adr/0008-dialog-persona-hybrid-authorship.md)).
- **Распределения, а не средние.** Скажите модели «твой типичный ответ - 90
  символов», и она будет писать ровно 90 символов каждый раз, а эта
  однородность и есть главный признак подделки. Вместо этого она получает
  медиану, 90-й перцентиль и долю коротких ответов - и варьирует так, как это
  делает человек.
- **Устаревание объявляется вслух.** Свежесть оценивается по трём осям, и вердикт
  называет сработавшую: **объём** (50 ваших новых сообщений), **возраст** (90
  дней) и **дрейф** (любой из пяти коэффициентов сдвинулся на 0.20 или медианная
  длина изменилась вдвое) (`SPEC-PSN-005`).

Персона никогда не блокирует отправку (`SPEC-PSN-008`), а её текстовые поля
очищаются от невидимых символов и отвергаются целиком, если содержат ссылку,
@-хендл, имя инструмента или маркер-ограждение (`SPEC-PSN-006`).

Ничего из вашего стиля никуда не загружается. Все измерения - это числа в вашем
собственном PostgreSQL.

## Безопасность аккаунта

Управление личным аккаунтом через MTProto ставит вас под антиспам Telegram. Эти
защиты встроены и покрыты тестами, они не опциональны:

- **Сообщения незнакомым блокируются полностью.** Нет истории и нет в контактах -
  ничего не отправляется, вы получаете предупреждение с указанием на
  `tg_add_contact`. Флага `force` нет, и это принципиально.
- **Длинный текст режется** на части меньше лимита в 4096 символов, по границам
  предложений, никогда посреди слова.
- **Между частями пауза** 2.5 секунды. Именно всплески вызывают срабатывание
  лимитов.
- **Лимиты сообщаются, а не ретраятся.** `FloodWaitError` возвращается как «нужно
  подождать N секунд» вместо цикла повторов, который этот лимит продлевает.
- **Файл сессии - это полноценный доступ к аккаунту.** Он в `.gitignore` ещё до
  того, как появится, и получает права `0600`.
- **Всё локально.** База слушает `127.0.0.1`; Telegram видит тот же IP, с
  которого вы всегда заходите.
- **Содержимое сообщений - это данные, а не инструкции.** Всё прочитанное из
  Telegram написано другими людьми; инструкцию внутри сообщения нужно показать
  вам, а не выполнять.

Подробно: [docs/70-ops/security.md](../../70-ops/security.md).

## Как это устроено

Три процесса, потому что MCP-сервер работает через stdio и поэтому не может
спросить код из SMS:

| Процесс | Когда работает | Что делает |
| --- | --- | --- |
| `auth.py` | Один раз, в терминале | Логинится, создаёт `tg_session.session` |
| `sync_db.py` | По требованию | Переносит историю личных чатов в PostgreSQL |
| `server.py` | Запускается агентом | Отдаёт девять инструментов по stdio |

Поиск идёт в PostgreSQL, а не в Telegram - поэтому он мгновенный, безлимитный и
без риска бана. Плата за это - архив актуален на момент последнего
`just tg-sync`; разрыв закрывает `tg_get_recent_messages`, читающий вживую.

Архитектура: [docs/20-architecture/sad.md](../../20-architecture/sad.md).

## Частые вопросы

### Это Telegram-бот?

Нет. Боты работают через Bot API, не могут написать человеку первыми и явно
видны как боты. tg-ai управляет вашим настоящим аккаунтом через MTProto, поэтому
сообщения идут от вас и попадают в существующие чаты. Именно из-за этой силы и
существует Send Guard.

### Меня забанят?

Автоматизация личного аккаунта всегда несёт риск, и никто не может обещать
обратного - прочитайте дисклеймер выше. tg-ai построен так, чтобы удерживать вас
в рамках обычного человеческого поведения: он отказывается писать незнакомым,
выдерживает 2.5 секунды между частями, никогда не ретраит flood wait и работает с
вашего собственного IP. Отправка идёт по одному получателю за раз, массовой
рассылки нет по замыслу.

### Может ли он сам отвечать людям, пока я сплю?

Сам по себе - нет. **В этом репозитории нет LLM.** tg-ai - пассивный набор
инструментов: у него нет цикла и нет «мозгов», он спит, пока к нему не обратится
клиент. Чтобы получить автоответчик, нужен автономный агент поверх: он опрашивает
`tg_get_unread_dialogs`, читает `tg_get_dialog_persona`, генерирует ответ и
вызывает `tg_send_message`. Все ручки уже готовы; решение дёргать их - за вами.

### История переписки куда-то уходит?

Нет. Архив - это контейнер PostgreSQL на `127.0.0.1:5434`, файл сессии лежит в
репозитории с правами `0600`. Ничего никуда не загружается. Модель вашего
MCP-клиента видит только то, что вернул инструмент в ответ на ваш вопрос.

### Читает ли он группы и каналы?

Да, но подчёркнуто неохотно. Он читает группы и каналы, **на которые вы уже
подписаны**, и только те, которые вы назвали явно - обычная синхронизация
по-прежнему затрагивает только личные переписки.

Каждую группу можно прочитать не чаще раза в пять минут, не более двадцати
чтений в сутки и не более ста сообщений за раз - это ровно один запрос к API.
Счётчики хранятся в базе, поэтому перезапуск сервера их не обнуляет.

Он **никогда не вступит** в группу или канал за вас и не сможет прочитать то,
куда вы не вступили: поиск каналов, в которых вас нет, - это именно то
поведение, из-за которого личные аккаунты помечают как скраперы. Он не
запрашивает списки участников и не может написать тому, кого видел только
пишущим в группе. В канале он может опубликовать сообщение, только если вы там
администратор.

Боты и служебный аккаунт Telegram по-прежнему исключены.

## Команды

```bash
just              # список всех рецептов
just check        # ruff + black + pytest + проверки документации
just tg-sync      # обновить архив (инкрементально)
just tg-sync-targets @anna @bob    # архивировать только этих людей
just tg-sync-targets "Some Group"  # или группу, в которой вы состоите (максимум 5 за запуск)
just tg-status    # аккаунт, дата-центр, лимит запросов, аварийный стоп, архив
just tg-killswitch        # включён ли аварийный стоп и почему
just tg-killswitch-clear  # выключить его, проверив аккаунт вручную
just db-psql      # psql-консоль в архив
```

## Область применения

Текстовые переписки: личные разговоры с людьми плюс группы и каналы, на которые
вы уже подписаны, с жёсткими ограничениями на частоту и объём чтения. Не боты,
не медиа, и ничего, что удаляет или редактирует сообщения в вашем аккаунте. Он
никогда не вступает в группы, не запрашивает списки участников и не пишет тем,
кого видел только в группе. Ограничения:
[docs/10-product/prd.md](../../10-product/prd.md).
