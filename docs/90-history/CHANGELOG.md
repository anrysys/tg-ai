# Changelog

Newest first. One line per change. Generated by hand as part of the
[documentation maintenance protocol](../50-process/docs-maintenance-protocol.md).

## 2026-09-05

- Discoverability pass. The repository was complete but effectively invisible,
  and its quickstart hardcoded one developer's absolute path four times.
  - `README.md` rewritten: keyword-bearing title, badges, a `git clone` line and
    portable paths, a per-client install matrix (Claude Code, Claude Desktop,
    Cursor, Windsurf, VS Code, Codex, Antigravity, Gemini CLI, Cline and a
    generic block), a full Dialog Persona section naming all eighteen measured
    style signals, and a nine-question FAQ.
  - `USE-CASES.md`: forty worked scenarios with copy-paste prompts, grouped by
    the job they do, plus an explicit "what this cannot do" section.
  - `docs/i18n/ru/`: Russian mirror of both pages. First use of the `i18n`
    exemption that AGENTS.md rule 1 has always reserved.
  - Machine-readable discovery surfaces: `llms.txt`, `llms-full.txt`,
    `server.json` (MCP Registry shape), `CITATION.cff`, `SECURITY.md`,
    `CODE_OF_CONDUCT.md` and `.github/ISSUE_TEMPLATE/`.
  - `scripts/build_site.py` generates `site/` - two HTML pages carrying
    schema.org `SoftwareApplication`, `HowTo` and `FAQPage` JSON-LD, OpenGraph
    tags, `robots.txt` and `sitemap.xml` - from the same markdown, stdlib only so
    no dependency was added. `just site-check` and a CI job fail if the committed
    output is stale, so the generated copy cannot drift from its source.
  - `site/og.png`: the 1280x640 social preview the repository never had. The logo
    is SVG, and GitHub social previews must be raster.
  - Two new documentation-map rows, for the public pitch and for the crawler
    surfaces.
- Fixed a documentation defect found while writing the above:
  [sad.md](../20-architecture/sad.md) claimed `tg_get_dialog_persona` refreshes
  the stored measurements. It does not - it re-measures the frozen window on
  every call and stores nothing. `tg_set_dialog_persona` is the only writer.
- **Fixed CI, which had been red on `main` since the first push.** `ci.yml` ran
  bare `pytest`, which puts only `tests/` on `sys.path`, so
  `import tg_ai` in `tests/conftest.py` raised `ModuleNotFoundError` and the job
  exited 4. `just py-test` runs `python -m pytest`, which puts the repository
  root on the path, so the suite passed locally and failed in CI - the exact
  shape of failure nobody notices. CI now uses `python -m` for ruff, black and
  pytest, matching the Justfile.
- `TASK-012` (package for PyPI so the install is `uvx`, needs a superseding ADR)
  and `TASK-013` (`db.rebaseline_persona` has no call sites) recorded.

- Dialog Persona: per-Dialog writing style, so a drafted reply sounds like the
  user rather than like a model (`SPEC-PSN-001`..`008`,
  [ADR-0008](../20-architecture/adr/0008-dialog-persona-hybrid-authorship.md)).
  - New `dialog_personas` table, separate from `dialogs` because
    `_UPSERT_DIALOG_SQL` rewrites that table on every sync.
  - New `tg_ai/persona.py`: language-agnostic Style Metrics - length
    distribution, burst rate, capitalisation, punctuation, emoji, Unicode script
    mix - measured from the account's own messages only, and incapable of
    emitting message text.
  - Three new tools: `tg_get_dialog_persona`, `tg_set_dialog_persona`,
    `tg_list_dialog_personas`. Nine tools in total.
  - `tg_get_recent_messages` now prepends the Dialog's Persona block, degrading
    to one line when the archive is unreachable.
  - `tg_send_message` gained a docstring line and a post-delivery hint. Its Send
    Guard is byte-for-byte unchanged, and nothing in this feature can refuse a
    send (`SPEC-PSN-008`).
  - Persona Baseline frozen on creation, so replies this server drafts cannot
    feed back into the measurements (`SPEC-PSN-003`).
  - `RISK-07`: persistent prompt injection through a stored Persona, with
    structural sanitisation in `safety.sanitise_persona_field`.
  - Dialog Lookup (`SPEC-SRCH-006`): Archive-only Target resolution, exact per
    key, ambiguity reported and never guessed.
  - 88 new offline tests; 152 in total.
- `just db-reset` now prints the message, dialog and persona counts it is about
  to destroy and refuses to continue until `DELETE` is typed on an interactive
  terminal. It was previously unguarded, and it is the one command that can
  destroy a Dialog Persona.
- Documentation map gained the two rows this change proved were missing:
  user-facing capability, and a new module under `tg_ai/`.

- Added SVG project emblem and logo to README.md (`docs/assets/logo.svg`).
- Targeted sync: `sync_db.py --targets` and `just tg-sync-targets` restrict a run
  to named people, so a large account can archive what matters without waiting out
  a full backfill (`SPEC-SYNC-006`). Unmatched targets are reported by name.

## 2026-09-04

- Search and the health check now degrade gracefully when Telegram
  credentials are absent; the credential check moved to `server.telegram()`.
- Initial implementation: M0 through M4 complete.
- `auth.py`, `sync_db.py`, `server.py` and the `tg_ai` package.
- Six MCP tools: `tg_send_message`, `tg_get_recent_messages`,
  `tg_get_unread_dialogs`, `tg_search_local_history`, `tg_add_contact`,
  `tg_whoami`.
- PostgreSQL archive: composite primary key, generated `tsvector`,
  GIN plus trigram indexes.
- Anti-ban rules implemented and tested: Send Guard, 4000-character chunking,
  2.5s pacing, flood-wait translation, never-raise tool boundary.
- ADR-0001 through ADR-0007.
- Documentation base per the router, map and maintenance protocol.
