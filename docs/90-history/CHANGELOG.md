# Changelog

Newest first. One line per change. Generated by hand as part of the
[documentation maintenance protocol](../50-process/docs-maintenance-protocol.md).

## 2026-09-05

- Dialog Persona: per-Dialog writing style, so a drafted reply sounds like the
  user rather than like a model (`SPEC-PSN-001`..`008`,
  [ADR-0008](../20-architecture/adr/0008-dialog-persona-hybrid-authorship.md)).
  - New `dialog_personas` table, separate from `dialogs` because
    `_UPSERT_DIALOG_SQL` rewrites that table on every sync.
  - New `tg_ai/persona.py`: language-agnostic Style Metrics - length
    distribution, burst rate, capitalisation, punctuation, emoji, Unicode script
    mix - measured from the account's own messages only, and incapable of
    emitting message text.
  - Three new tools: `tg_get_dialog_persona`, `tg_set_dialog_persona`,
    `tg_list_dialog_personas`. Nine tools in total.
  - `tg_get_recent_messages` now prepends the Dialog's Persona block, degrading
    to one line when the archive is unreachable.
  - `tg_send_message` gained a docstring line and a post-delivery hint. Its Send
    Guard is byte-for-byte unchanged, and nothing in this feature can refuse a
    send (`SPEC-PSN-008`).
  - Persona Baseline frozen on creation, so replies this server drafts cannot
    feed back into the measurements (`SPEC-PSN-003`).
  - `RISK-07`: persistent prompt injection through a stored Persona, with
    structural sanitisation in `safety.sanitise_persona_field`.
  - Dialog Lookup (`SPEC-SRCH-006`): Archive-only Target resolution, exact per
    key, ambiguity reported and never guessed.
  - 88 new offline tests; 152 in total.
- Documentation map gained the two rows this change proved were missing:
  user-facing capability, and a new module under `tg_ai/`.

- Added SVG project emblem and logo to README.md (`docs/assets/logo.svg`).
- Targeted sync: `sync_db.py --targets` and `just tg-sync-targets` restrict a run
  to named people, so a large account can archive what matters without waiting out
  a full backfill (`SPEC-SYNC-006`). Unmatched targets are reported by name.

## 2026-09-04

- Search and the health check now degrade gracefully when Telegram
  credentials are absent; the credential check moved to `server.telegram()`.
- Initial implementation: M0 through M4 complete.
- `auth.py`, `sync_db.py`, `server.py` and the `tg_ai` package.
- Six MCP tools: `tg_send_message`, `tg_get_recent_messages`,
  `tg_get_unread_dialogs`, `tg_search_local_history`, `tg_add_contact`,
  `tg_whoami`.
- PostgreSQL archive: composite primary key, generated `tsvector`,
  GIN plus trigram indexes.
- Anti-ban rules implemented and tested: Send Guard, 4000-character chunking,
  2.5s pacing, flood-wait translation, never-raise tool boundary.
- ADR-0001 through ADR-0007.
- Documentation base per the router, map and maintenance protocol.
